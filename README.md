# Moloko's Dagwood & Wings — Website

Professional collection-only ordering site for Moloko's in Soshanguve.

## Changes made

- **Collection focused**: Customers choose collection time (no delivery/type options). Order flow and WhatsApp message clearly state "Collection only".
- **Coming Soon on item pictures**: Every menu item image has a "COMING SOON" overlay badge.
- **Stylish homepage name**: Hero uses elegant serif styling for "MOLOKO'S" plus refined subtitle.
- **Space for more**: New "More Coming Soon" section with placeholder cards for future combos, offers, sides & drinks.
- **Professional polish**: Improved typography, spacing, glass-style top bar, clearer hierarchy, refined buttons and cards.

## How to use

1. Open `index.html` in a browser, or upload the whole folder to GitHub Pages / any static host.
2. Replace images in `assets/` with your real photos when ready (remove or keep the "COMING SOON" overlay in `script.js` → `cardHTML` function as needed).
3. Edit menu items, prices, hours and WhatsApp number in `script.js`.

## Files

- `index.html` — structure
- `style.css` — design
- `script.js` — menu, cart, order flow
- `assets/` — hero and menu images
